# 评分与报告规则

全部题目、选项顺序与模型版本固定；不用随机抽取人物，也不由大模型运行时决定结果。

每个选项对一个行为维度贡献 -3、-1、+1、+3。每个新测评的六个维度各三题，哈利波特保留八个维度各三题。题目交错出现，选项位置固定轮换。

维度分 = clamp(round(50 + 50 × 已选权重之和 / 本维度全部题目的最大绝对权重之和), 0, 100)。数字表示本次回答在两端之间的位置，不是相似百分比、正确率或能力分数。

人物距离 = sqrt(Σ 维度权重 × (使用者坐标 - 编辑人物坐标)² / Σ 维度权重)。按距离升序；相同距离用人物 ID 稳定排序。前两名差不大于 tieThreshold 时主动提示接近，仍展示三位候选。最近距离不小于28时说明整体组合与全部原型距离较大。

报告先按偏离中点程度选择三个突出维度，再为每个维度选一条与该维度整体方向一致、贡献最大的实际答案证据（同值按题号；中点使用绝对贡献）。相似维度按使用者与人物的坐标差排序；差异取差值最大的维度。所有文字保持回答方向一致，人物解释带版本与局限。

未完成、缺失、额外题号、未知选项一律拒绝评分。模拟结果只是覆盖检查，不是心理效度或真实用户研究。PNG卡片不包含逐题答案。
