# 另一面 · 测评游乐场

免费、非官方的娱乐与自我探索测评展示站，供朋友体验。

**入口：https://cosimoyxy.github.io/another-side/**

十款完整测评、186道题、92个人物／动物结果，每个结果都有图片。
主题包括三国、古典诗人、科学家、西游记、红楼梦、哈利波特、海贼王、火影忍者、吉卜力电影与原创动物人格。

支持分类与搜索、手机答题、当前标签页进度恢复、答案证据、相近候选和1080×1440 PNG结果卡下载。分享链接打开对应测评介绍页，不带答案或结果。

## 本地运行

```bash
python3 -m http.server 8765 --directory web --bind 127.0.0.1
```

打开 http://localhost:8765 。无需前端安装、构建、账号、付款或API Key。

## 工程

- `web/`：实际站点文件和本地图片，GitHub Actions发布此目录。
- `content/`：十款完整结构化题库、候选坐标、来源、解释和素材状态。
- `docs/scoring-rules.md`：可复现算法与报告依据。
- `release.json`：已验证核心代码及全部发布文件的SHA-256。
- `.github/workflows/pages.yml`：main分支自动部署到GitHub Pages。

本地验收完成了1762组算法对照、全部186题的十款浏览器答题流程、92个候选报告与图片卡，以及360／390／768／1280宽度检查。模拟答案不是真实用户研究，没有心理效度或准确率承诺。

答案仅保留在当前标签页的sessionStorage，不上传；关闭标签页或使用页脚清除按钮即可移除。页面不加载第三方统计脚本或远程图片，不收费。

## 内容与素材

题目、评分维度和人物坐标为本工程创作；人物结果仅表达一个侧面，不评价智商、健康、能力或道德。参考Arealme中文站的分类浏览方式，未复制其题库或视觉设计。

第三方角色、作品名称及图片的公开复用权限仍为REVIEW；用户的朋友测试部署请求不构成第三方授权。本项目与相应作品、作者、工作室及权利人没有官方合作关系。结构化数据保留逐项来源和素材状态；原始插画、完整检查截图和维护源码另保留在本地工程。
